### 01. Code4Care — AI Hospital Surveillance

**Status:** `Live` | **Live App:** [your-live-link-here](#) | **Repo:** [lalitmali04/Code4Care](https://github.com/lalitmali04/Code4Care)

Real-time hospital surveillance platform that flags infection risk using ML and visualises it on a 3D digital-twin dashboard.

```text
┌──────────────────────────────────────────────────────────────────────────┐
```
